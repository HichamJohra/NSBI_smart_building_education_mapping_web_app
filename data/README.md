# Data

`smart_building_education_dataset.xlsx` holds one row per educational offer (sheet `courses`), the
`data_dictionary` sheet that drives the app, the `vocabulary` sheet with the harmonised values, and the
`sources` sheet. See the `README` sheet inside the workbook and `docs/data_model.md`.
Close the file in Excel before committing (Excel lock files `~$*.xlsx` are git-ignored).
